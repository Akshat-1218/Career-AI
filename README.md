# 🚀 CareerPilot AI

CareerPilot AI is an AI-powered career assistance platform designed to help students and job seekers prepare for their careers, improve their resumes, explore job opportunities, and generate personalized career guidance.

The application combines a modern React frontend with a Node.js/Express backend, MongoDB for data storage, and Google's Gemini AI for intelligent career-related features.

---

## ✨ Features

- 🔐 User Registration & Login
- 👤 User Profile Management
- 🤖 AI-Powered Career Assistance
- 📄 Resume Analysis
- 📝 Resume-Based Career Recommendations
- 💼 Job Description Generation
- 🎯 Personalized Career Guidance
- 🔎 Job/Career Information
- 📊 User Dashboard
- 🔑 JWT-based Authentication
- 🗄️ MongoDB Database
- ⚡ React + Vite Frontend
- 🧠 Google Gemini AI Integration
